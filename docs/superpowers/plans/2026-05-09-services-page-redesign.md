# services.html Hub Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reframe `services.html` as a scannable hub page that pushes link weight to the dedicated commercial pages (weddings/funerals/corporate/christmas) and contact for memorials. Editorial marquee-quote hero, 5 occasion entries, 6-card ensemble grid, swapped FAQ Q3, and two in-scope JSON-LD audit fixes.

**Architecture:** Edit `css/components.css` to add new component rules (`.pull-quote--marquee`, `.occasion-list`, `.ensemble-grid` / `.ensemble-card`), run `build.sh` to propagate inlined CSS to all pages, then edit the body markup of `services.html` directly section-by-section. Update the JSON-LD block in the same file to fix audit findings and reflect content changes. No new files, no JS, no images.

**Tech Stack:** Static HTML + inlined CSS (regenerated by `build.sh`), Python `validate_jsonld.py` for schema validation. No test framework — verification is via build success, JSON-LD validation, and browser preview at 320/768/1280px.
