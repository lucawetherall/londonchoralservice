Where the strip's data comes from

  • Bank: Starling, read-only, whenever a page shows the bank (a ten-minute cache). When a read fails, its chip clears the cache so the next page tries again.
  • Books: cc_sync.py books, every 30 minutes from 07:00 to 22:00. A stale or failed chip runs it now.
  • Drafts and Diary: the enquiry assistant's daily pass reads Zoho Drafts and Google Calendar and writes them here. The app can't read Mail or the calendar itself, so it can't sync them: use Run now on the enquiry assistant in the Claude app (Routines).
  • Ads: the Monday review writes the Ads summary once a week. Use Run now on the weekly review in the Claude app if it is late.
  • Marketing: cc_sync.py marketing, once a day from 07:00. A stale or failed chip runs it now.
